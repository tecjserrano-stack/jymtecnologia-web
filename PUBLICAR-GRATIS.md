# Publicar JYM Tecnología sin pagar hosting ni dominio

La página ya está preparada en un repositorio local de GitHub Desktop, en la rama `main`. GitHub Pages puede alojar esta web estática gratis y asignarle una dirección `github.io`, por ejemplo `https://TU-USUARIO.github.io/jymtecnologia-web/`.

## Publicar el repositorio

1. Inicia sesión en GitHub Desktop con tu cuenta de GitHub. La autenticación se completa directamente en la aplicación o en el navegador.
2. Abre el repositorio local `jymtecnologia-web`.
3. Pulsa **Publish repository**.
4. Usa el nombre `jymtecnologia-web` y elige tu cuenta como propietario.
5. Para usar Pages en GitHub Free, deja el repositorio **Público** (desactiva **Keep this code private** si aparece marcado).
6. Publica el repositorio.

## Activar GitHub Pages

1. Abre el repositorio publicado en GitHub.com.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
5. Cuando termine el despliegue, la dirección pública aparecerá en **Settings → Pages**.

## Antes de confirmar la publicación

- El repositorio público hace visible el código y los archivos del sitio. Revisa que los datos comerciales publicados sean los correctos.
- El formulario abre WhatsApp con un mensaje preparado; la página no lo envía automáticamente ni almacena datos.
- La foto de portada y los gráficos de servicios son ilustrativos. Añade fotos propias antes de presentar trabajos específicos como proyectos realizados por JYM.
- La dirección gratuita será un subdominio `github.io`; no se compra un dominio `.com`.

Documentación oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
